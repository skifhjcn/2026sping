# whatieattoday 🍽️
> *손으로 쓴 다이어리처럼, 매일의 식사를 기록하는 앱*

**2026 Spring Semester Project**
학번: 2023130862 | 이채민

---

## 소개

**whatieattoday**는 매일 먹은 음식을 캘린더 형식으로 기록하는 식단 관리 다이어리 앱입니다.
뉴모피즘(Neumorphism) 디자인과 Caveat 손글씨 폰트를 활용해, 디지털이지만 마치 종이 다이어리에 적는 것 같은 아날로그 감성을 줍니다.
음식 사진을 직접 찍어 올리거나, 메뉴 이름만 입력하면 Claude AI가 귀여운 SVG 일러스트를 자동으로 생성해 칸을 채워줍니다.

---

## 주요 기능

### 1. 주간 식사 캘린더
- 월~일 7일 그리드에 **아침 / 점심 / 저녁** 슬롯이 표시됩니다.
- 좌우 화살표 버튼으로 원하는 주를 탐색할 수 있습니다.
- 오늘 날짜의 요일 레이블은 강조 색상으로 표시됩니다.
- 기록이 완료된 슬롯에는 사진 썸네일 또는 AI 일러스트가 미리보기로 채워집니다.

### 2. 식사 기록 (상세 뷰)
슬롯을 탭하면 해당 날짜·끼니의 상세 입력 화면이 열립니다.

| 기능 | 설명 |
|------|------|
| 📷 사진 첨부 | 기기에서 음식 사진을 직접 업로드합니다. |
| ✦ AI 픽토그램 생성 | 메뉴 이름을 입력하면 Claude API가 해당 음식을 표현하는 귀여운 SVG 일러스트를 생성합니다. |
| 📝 메뉴 이름 + 한 줄 일기 | 오늘 뭘 먹었는지, 맛은 어땠는지 짧게 적어둡니다. |
| 🏷️ 기분 태그 | 맛있었어 / 건강했어 / 과식했어 / 아쉬웠어 / 특별했어 / 간단했어 중 선택합니다. |

> 사진을 올리지 않아도 AI 일러스트만으로 캘린더를 예쁘게 채울 수 있습니다.

### 3. Seasonal Food Guide (제철 음식 매거진)
- 메인 화면 하단에 **"Seasonal Food Guide"** 배너가 표시됩니다.
- 탭하면 현재 시즌 추천 음식 카드들이 모달로 열립니다.
- 각 카드에는 제철 음식 소개, 추천 조리법, 계절 키워드 태그가 포함됩니다.
- 현재 버전은 봄 시즌 기준으로 꽃게, 대저 짭짤이 토마토, 버터떡 등을 소개합니다.

### 4. 디자인 시스템
- **뉴모피즘(Neumorphism)** 스타일의 아이보리 톤 UI — 버튼과 카드가 배경에서 살짝 떠오르거나 눌리는 입체감을 줍니다.
- **Caveat** 손글씨 폰트를 전면 적용해 손으로 쓴 다이어리 분위기를 연출합니다.
- 주 컬러 팔레트: `#f0ece0` (아이보리 배경) / `#a89070` (브라운 골드 액센트) / `#5a4e3c` (메인 텍스트)

## 향후 개발 계획: 소셜 식단 공유 기능

> 앞으로 친구를 추가하고 서로의 식단을 구경할 수 있는 소셜 기능을 추가할 예정입니다.

### 구현 방향

**① 백엔드 및 사용자 인증**
현재는 브라우저 메모리에만 데이터가 저장되므로, 공유 기능을 위해서는 서버 기반 저장소가 필요합니다.
- **사용자 계정 시스템** 도입 (이메일/소셜 로그인)
- **REST API 또는 Firebase** 등을 활용한 식단 데이터 클라우드 저장
- 각 기록에 `userId`, `visibility` (공개/친구공개/비공개) 필드 추가

**② 친구 추가 및 팔로우**
- 닉네임 또는 고유 코드로 친구 검색 및 요청
- 친구 요청 수락/거절 관리
- 팔로우 기반의 단방향 공개 or 맞팔 기반의 양방향 공유 중 선택

**③ 친구 피드**
- 친구들의 오늘/이번 주 식단을 타임라인 형식으로 모아보는 **피드 뷰** 추가
- 각 기록에 💬 댓글이나 🫶 리액션(이모지 반응) 기능 추가
- "친구는 오늘 이걸 먹었어요" 형식의 알림 지원

**④ 공개 범위 설정**
- 슬롯별로 **전체공개 / 친구공개 / 나만보기** 세 단계로 공개 범위 설정
- 기분 태그나 한 줄 일기는 선택적으로 숨길 수 있도록 프라이버시 보호

**⑤ 데이터 흐름 예시**
```
[사용자 A 기록 저장]
    ↓  POST /api/entries  (meal, photo, aiSvg, tags, visibility)
[서버 DB 저장]
    ↓
[친구 B의 피드 요청]
    ↓  GET /api/feed?userId=B
[B의 친구 목록 조회 → A의 공개 기록 필터링 → 반환]
    ↓
[친구 피드 UI 렌더링]
```
