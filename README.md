## 소개

**whatieattoday**는 매일 먹은 음식을 캘린더 형식으로 기록하는 식단 관리 다이어리 앱입니다.
뉴모피즘(Neumorphism) 디자인과 Caveat 손글씨 폰트를 활용해, 디지털이지만 마치 종이 다이어리에 적는 것 같은 아날로그 감성을 줍니다.

**이번 파이널 버전에서는** 중간 발표 때 *"향후 개발 계획"* 으로만 제시했던 소셜 기능을 실제로 구현했습니다.
친구를 추가하고, 친구의 식탁에 **직접 손그림과 한마디를 남기는 교환일기** 기능이 핵심입니다.

## 주요 기능

### 1. 주간 식사 캘린더 (개인 다이어리)
- 월~일 7일 그리드에 **아침 / 점심 / 저녁** 슬롯이 표시됩니다.
- 좌우 화살표 버튼으로 원하는 주를 탐색할 수 있습니다.
- 오늘 날짜의 요일 레이블은 강조 색상으로 표시됩니다.
- 기록이 완료된 슬롯에는 사진 썸네일 또는 메뉴 미리보기가 채워집니다.
- 🆕 친구가 내 식탁에 한마디를 남기면 해당 슬롯에 **빨간 점**으로 표시됩니다.

### 2. 식사 기록 (상세 뷰)
슬롯을 탭하면 해당 날짜·끼니의 상세 입력 화면이 열립니다.

| 기능 | 설명 |
|------|------|
| 📷 사진 첨부 | 기기에서 음식 사진을 직접 업로드합니다. |
| 📝 메뉴 이름 + 한 줄 일기 | 오늘 뭘 먹었는지, 맛은 어땠는지 짧게 적어둡니다. |
| 🏷️ 기분 태그 | 맛있었어 / 건강했어 / 과식했어 / 아쉬웠어 / 특별했어 / 간단했어 중 선택합니다. |
| 🆕 🌏 공개 범위 | 전체공개 / 친구공개 / 나만보기 중 선택해 슬롯별 공개 수준을 조절합니다. |

### 3. 🆕 친구 시스템
- 닉네임 또는 **고유 코드**(예: `GRP-MINA`)로 친구를 검색합니다.
- 친구 요청을 보내고, 받은 요청을 **수락 / 거절**할 수 있습니다.
- 수락 시 **양방향**으로 친구 관계가 맺어지며, 친구 목록에서 관리합니다.
- 받은 요청 개수는 하단 탭과 상단 종 아이콘에 **배지**로 표시됩니다.

### 4. 🆕 친구 피드
- 친구들의 공개된 식단을 **최신순 타임라인**으로 모아봅니다.
- 각 카드에는 작성자 · 날짜 · 끼니 · 메뉴 · 한 줄 일기 · 기분 태그 · 공개 범위가 표시됩니다.
- 공개 범위 로직에 따라, **친구가 아닌 사용자의 친구공개 기록은 피드에 나타나지 않습니다.**
- 카드를 탭하면 해당 식탁의 교환일기 화면으로 이동합니다.

### 5. 🆕 교환일기 (Exchange Diary) ⭐ 핵심 기능
친구의 식탁에 손그림과 한마디를 남기는, 이 앱의 가장 특별한 기능입니다.

- **HTML5 Canvas**에 직접 손그림을 그립니다. (5색 펜 / 지우개 / 전체 지우기)
- 손그림과 함께 짧은 **한마디 메시지**를 남깁니다.
- 하나의 식탁에 여러 친구가 남긴 교환일기가 **시간순으로 누적**됩니다.
- 한마디를 남기면 식탁 주인에게 **알림**이 전달됩니다.

### 6. 🆕 알림
- 누가 내 식탁에 한마디를 남겼는지, 친구 요청·수락이 있었는지 알림으로 확인합니다.
- 읽지 않은 알림은 강조 표시와 **배지 카운트**로 구분됩니다.

### 7. 🆕 계정 전환 (데모 모드)
- 별도 로그인 없이 소셜 기능을 시연할 수 있도록, 여러 사용자 계정을 즉석에서 전환합니다.
- 계정을 바꾸면 **친구 관계 · 공개 범위 · 알림**이 각 사용자 시점에 맞게 다르게 보입니다.

### 8. Seasonal Food Guide (제철 음식 매거진)
- 메인 화면 하단 배너를 탭하면 현재 시즌 추천 음식 카드가 모달로 열립니다.
- 봄 시즌 기준으로 꽃게, 대저 짭짤이 토마토, 버터떡 등을 소개합니다.

### 9. 디자인 시스템
- **뉴모피즘(Neumorphism)** 스타일의 아이보리 톤 UI — 버튼과 카드가 배경에서 살짝 떠오르거나 눌리는 입체감을 줍니다.
- **Caveat** 손글씨 폰트를 전면 적용해 손으로 쓴 다이어리 분위기를 연출합니다.
- 주 컬러 팔레트: `#f0ece0` (아이보리 배경) / `#a89070` (브라운 골드 액센트) / `#5a4e3c` (메인 텍스트)

## 구현 포인트

중간 버전에서 *"향후 개발 계획"* 으로 적었던 항목들을, 백엔드 없이 클라이언트에서 동작하도록 실제 구현했습니다.

**① 다중 사용자 데이터 모델**
사용자, 친구 관계(그래프), 식단 기록, 교환일기 노트, 알림을 분리된 엔티티로 설계하고, 계정 전환 시 시점에 따라 다른 데이터가 노출되도록 구성했습니다.

**② 공개 범위 기반 접근 제어**
각 기록의 `visibility`(전체공개 / 친구공개 / 나만보기) 값과 친구 관계를 함께 판정해, 피드에 노출할 기록을 필터링합니다.

```
isVisible(기록, 보는사람):
    내 기록이면            → 노출
    나만보기면             → 숨김
    전체공개면             → 노출
    친구공개면             → (보는사람이 작성자의 친구일 때만) 노출
```

**③ Canvas 손그림 구현**
HTML5 Canvas로 마우스·터치 드로잉을 직접 구현했으며, 그린 결과를 이미지 데이터(`toDataURL`)로 변환해 교환일기 노트에 저장합니다.

**④ 상호작용 → 알림 흐름**
```
[채민] → 미나의 식탁에 손그림 + 한마디 남기기
    ↓  교환일기 노트 추가 (by, text, draw, ts)
[미나의 기록에 note 저장]
    ↓  미나에게 알림 생성
[미나로 계정 전환]
    ↓  🔔 알림 확인 + 본인 식탁 슬롯에 빨간 점 표시
```

## 실행 방법

별도 설치 없이 `whatieattoday_social.html` 파일을 브라우저에서 열면 바로 실행됩니다.

```
1. whatieattoday_social.html 열기
2. 우측 상단 계정 칩을 눌러 사용자 전환 (채민 / 미나 / 준호 / 소아)
3. [피드] 탭에서 친구 식단 → 교환일기 손그림 남기기
4. 계정 전환 후 [알림]에서 상호작용 확인
```

> ⚠️ 데이터는 브라우저 메모리에 저장되어 **새로고침 시 초기 데모 데이터로 리셋**됩니다.
